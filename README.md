# spm-resolve

[中文](README_zh.md)

Resolve a Swift package's dependency closure and print its pins, or print repository entries that can be pasted into a [depctl](https://github.com/0x1306a94/depctl) DEPS file.

Resolution is written under `~/Library/Caches/org.spm.resolve/<package-name>` and does not modify the target package. For why SwiftPM's `mirrors.json` is not used, see [docs/why.md](docs/why.md).

## Requirements

- macOS 15
- Swift 6.4

## Build

```sh
swift build --product spm-resolve
```

## Usage

`spm-resolve --version` prints the tool version. `--version <version>` after a package URL is the exact version of that remote package.

To vendor a remote package, resolve its dependency closure, let depctl fetch it, then rewrite the manifests to local paths.

```sh
spm-resolve https://github.com/hackiftekhar/IQKeyboardManager.git --version 8.0.3 --depctl
```

Use `--revision` instead of `--version` for a commit. `--depctl` prints repository entries for a DEPS file, including IQKeyboardManager itself and its dependencies. Merge that fragment into DEPS and run depctl. The packages land in `third_party/Packages/<repository-name>`.

After the sync, rewrite the fetched package:

```sh
spm-resolve rewrite third_party/Packages/IQKeyboardManager --dir-prefix ..
```

`--dir-prefix` is relative to the package being rewritten. A sibling dependency becomes a path such as `../IQKeyboardNotification`. A URL with no matching package under `--dir-prefix` is left unchanged.

`--depctl` prints the objects inside `repos.common`. Merge them into DEPS, and run the rewrite from `actions` after the sync:

```json
{
  "version": "1.4.5",
  "vars": {
    "GITHUB": "https://github.com"
  },
  "repos": {
    "common": [
      {
        "url": "${GITHUB}/hackiftekhar/IQKeyboardManager.git",
        "commit": "0972dd6eded87c930fb6ad36b3c5ecd620f06894",
        "dir": "third_party/Packages/IQKeyboardManager",
        "comment": "8.0.3 version Generated by spm-resolve"
      },
      {
        "url": "${GITHUB}/hackiftekhar/IQKeyboardNotification.git",
        "commit": "efa705d7200edd95b6e31e65e25171f7e897f995",
        "dir": "third_party/Packages/IQKeyboardNotification",
        "comment": "1.0.7 version Generated by spm-resolve"
      }
    ]
  },
  "actions": {
    "common": [
      {
        "command": "spm-resolve rewrite third_party/Packages/IQKeyboardManager --dir-prefix ..",
        "dir": "."
      }
    ]
  }
}
```

depctl reads `url`, `commit`, and `dir`. `comment` is only a note. `actions` run after the repositories are synced.

```text
spm-resolve <package> [--depctl] [--dir-prefix <path>]
spm-resolve <url> --version <version> [--depctl] [--dir-prefix <path>]
spm-resolve <url> --revision <commit> [--depctl] [--dir-prefix <path>]
```

`<package>` may be a package directory or `Package.swift`. An argument containing `://` or starting with `git@` is a remote repository and requires exactly one of `--version` or `--revision`. `--version` resolves an exact version. A remote resolve writes a temporary package at `~/Library/Caches/org.spm.resolve/<repository-name>/<version-or-revision>`. The result includes that repository and its dependency closure. The temporary package is omitted.

A line `--- spm-resolve ---` is printed before the result so it can be separated from resolve logs. By default every pin is printed as `kind`, `location`, `revision`, and `label`, separated by tabs:

```text
--- spm-resolve ---
git	https://github.com/example/Example.git	0123abcd	1.0.9
```

`--depctl` prints only remote Git dependencies, with fields in the order `url`, `commit`, `dir`, `comment`. `dir` defaults to `third_party/Packages/<repository-name>`. `--dir-prefix` changes the prefix. `comment` ends with `Generated by spm-resolve`. Entries are sorted by URL.

```text
spm-resolve Packages/xxx --depctl
```

```text
--- spm-resolve ---
[
  {
    "url": "https://github.com/hackiftekhar/IQKeyboardCore.git",
    "commit": "0123abcd",
    "dir": "third_party/Packages/IQKeyboardCore",
    "comment": "1.0.9 version Generated by spm-resolve"
  }
]
```

path, registry, and local Git dependencies are skipped with a `skip` line on standard error. An empty Git list prints `[]`.

## Rewrite

Run this after depctl has synced:

```text
spm-resolve rewrite <package> [--dir-prefix <path>]
```

`--dir-prefix` defaults to `third_party/Packages` and is relative to the package being rewritten. Absolute paths and `~` are used as given. The command follows dependency declarations from the root manifest. It does not resolve again and does not contact GitHub. Both `Package.swift` and `Package@swift-*.swift` in a package root are rewritten. A `.package(url:)` call becomes `.package(path:)` relative to that manifest. Existing path dependencies are left unchanged and are still followed. A registry dependency prints `skip registry` and is not changed. A URL with no package under `--dir-prefix` is left unchanged and prints `skip`.

Before rewriting, `Package.swift` is copied to `Package.swift.back` in the same directory. An existing backup is kept. On success, the rewritten manifest paths are printed.

```swift
// Packages/xx/Package.swift
.package(path: "../../third_party/Packages/IQKeyboardManager")

// third_party/Packages/IQKeyboardManager/Package.swift
.package(path: "../IQKeyboardNotification")
```

## Dependencies

`swift-package-manager` comes from `https://github.com/swiftlang/swift-package-manager.git`, pinned at `88d5888f7f74b979f36aac41b4972aed58936fa2`. The tool calls `Workspace.resolve` directly. That API follows SwiftPM mainline rather than a stable release. Rewriting uses `swift-syntax` 604.0.0, matching Swift 6.4.
